Weather App

A responsive weather application built with JavaScript that displays current weather conditions, a multi-day forecast, and a dynamic background image based on the current weather.

Live Demo: https://dksalty.github.io/weather_app/

Features:
- Search weather by city
- Current weather conditions
- 15-day forecast
- Dynamic weather backgrounds from Unsplash
- Switch between U.S. and Metric units
- Loading indicator while fetching data
- Responsive design for desktop and mobile
- Error handling for invalid searches or network issues

Built With:
- JavaScript (ES6 Modules)
- HTML5
- CSS3
- Webpack
- Visual Crossing Weather API
- Unsplash API
